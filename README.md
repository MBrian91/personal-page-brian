## Seccion de colaboracion

Para mantener el código organizado y asegurar la calidad del proyecto, seguimos un flujo de trabajo estructurado basado en las prácticas de GitHub:
• Feature Branching: Cada nueva funcionalidad, corrección de errores o mejora se desarrolló en una rama (branch) independiente y descriptiva, evitando cambios directos en la rama principal.
• Gestión de Issues: Utilizamos Issues para registrar tareas, reportar fallos y debatir las propuestas de mejora antes de escribir el código.
• Pull Requests (PRs): La integración de código se realizó exclusivamente mediante Pull Requests. Cada PR fue revisado y validado para garantizar que cumpliera con los estándares del proyecto antes de fusionarse.
