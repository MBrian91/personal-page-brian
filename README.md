### Cómo trabajamos en equipo

Para no pisarnos el código y llevar el proyecto adelante de forma ordenada, usamos un flujo de trabajo súper limpio con GitHub:
1. Feature Branching: No trabajamos sobre el main directamente. Cada uno trabajó sus tareas en ramas separadas para mantener el código a salvo. Por ejemplo, usamos:
	• mejorar-readme
	• completar-archivo-contacto
	• correciones-en-el-index
2. Uso de Issues: Nos organizamos creando Issues para cada tarea o mejora. Así sabíamos perfectamente qué estaba haciendo cada quién y qué faltaba por terminar.
3. Pull Requests (PRs): Cuando terminábamos una rama, armábamos un Pull Request. El resto del equipo revisaba los cambios, dábamos el visto bueno y recién ahí sumámos el código al proyecto principal.
